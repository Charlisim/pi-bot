# Roadmap

Pi Bot follows a local-first path. Each phase must keep one source of truth and explicit authority boundaries.

## 0.1 — Agent Studio

- [x] Empty first-run workspace.
- [x] Create, edit, delete, and run custom agents.
- [x] Identity, role, personality, instructions, tools, model policy, and channels.
- [x] Responsive Pi TUI dashboard.
- [x] Durable local state and run receipts.
- [x] Human confirmation for elevated tools.

## 0.2 — Team workflows

- Topic threads and bounded channel briefs.
- Human decision gates.
- Finite feedback loops.
- Run detail and stop/steer controls through public pi-subagents RPC.
- Import and export after a reviewed schema contract.

## 0.3 — Automations

- Durable schedules.
- Signed GitHub and generic webhook envelopes.
- Event deduplication and replay protection.
- Dirty-channel pulses instead of permanent model processes.

## Later

- Orca adapter for managed worktrees, terminals, and browser flows.
- Herdr adapter for visible panes and human intervention.
- Slack projection with signed event intake.
- Optional shared control plane for multi-user teams.

Pi Bot will not add autonomous permission changes, hidden telemetry, unbounded agent chatter, or default agents.
