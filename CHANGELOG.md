# Changelog

## 0.1.2 — 2026-08-26

- Keep run details open after the Enter key opens them.
- Use Escape or `q` to return to the dashboard from run details.

## 0.1.1 — 2026-08-26

- Add left and right navigation between dashboard columns.
- Add row selection for channels and recent runs.
- Add direct run inspection from the dashboard and `/pi-bot inspect`.

## 0.1.0 — 2026-08-26

- Add first-run onboarding with no default agents.
- Add custom bot creation, editing, deletion, and execution.
- Add personality, tool, model, channel, and activation configuration.
- Add a responsive Pi-native dashboard.
- Add durable local state and async run receipts.
- Add security, contribution, architecture, and roadmap documentation.
- Use pnpm for deterministic development and CI installs.
